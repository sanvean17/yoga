# Yoga suave para principiantes mayores · guion 1 hora

- `yoga_guion_suave_ES.pdf` — guion en español para leer en voz alta (4 páginas A4).
- `yoga_guion_suave_FR.pdf` — la misma clase en francés, mismo orden y mismos números (4 páginas A4).

Estructura: parte 1 sentados (suelo o silla) · parte 2 de pie con silla o pared · parte 3 suelo o silla.

Regenerar: `cd src && python3 build_senior.py es && node print.js ../build/yoga_guion_suave_ES.html ../yoga_guion_suave_ES.pdf`
(idem con `fr`). Figuras vectoriales: `src/figures.py`, `src/poses.py`.
